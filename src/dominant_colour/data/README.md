# Colour naming lookup table

`w2c.txt` is the trained lookup table from van de Weijer's Color Naming
model. Each row is a bin's R, G, B centre followed by the probability of
that bin being called each of the 11 basic colours.

Source: https://github.com/Flipajs/color_naming_Weijer
Original: http://lear.inrialpes.fr/people/vandeweijer/color_names.html

J. van de Weijer, C. Schmid, J. Verbeek, D. Larlus. Learning Color Names
for Real-World Applications. IEEE Transactions on Image Processing, 2009.
